# Sagheer Labs

We're two students from the **UAE** building efficient AI LLMs from scratch.

**Our mission:** Make AI accessible so even devices that arent powerful can run capable models.

### What we do
- Design and train LLMs from the ground up
- Optimize for performance on low resource hardware
- Push towards efficient, scalable AI that runs anywhere

### Why
AI shouldnt be limited to massive server farms. We believe powerful models should run on the devices people already have.

Sagheer Labs, big ideas, smaller models.
